# SD4G — Service Design for Good

Landing page for the **SD4G Lab** at Dongseo University, Busan.

Implemented from the Figma design as a single static page — no build step,
no dependencies, no backend.

## Files

- `index.html` — the whole page (markup + CSS)
- `assets/` — icons and illustrations exported from Figma as SVG

## Viewing it

Open `index.html` in any browser.

## Notes

- Type is Plus Jakarta Sans, loaded from Google Fonts.
- The layout follows the Figma design at 1440px, and collapses to a single
  column with a horizontally scrollable card rail on narrower screens.
- The email field is presentational only — it does not submit anywhere yet.
